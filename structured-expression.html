Structure · Argument · Decision

结构化表达，
是让别人看得见你的判断。

不是把话说得像咨询报告，也不是往内容里塞更多框架。真正的结构，是把一个问题压缩成清楚的结论、同层理由、可追溯证据、适用边界和下一步行动。

思考时可以从下往上发现答案；表达时通常从上往下交付答案。 人决定问题、标准与取舍，Agent 负责分组、找缺口、模拟反驳和生成不同长度版本。

先校正一个误区

金字塔原理是成熟的商业表达方法，不是脑科学定律。它能降低读者寻找重点的成本，却不能替代事实、因果、证据与诚实；“结构清楚”不等于“结论正确”。

同一个结构，两种运动方向

想清楚与说清楚，不一定按同一顺序

真实工作往往先有碎片，没有答案。先自下而上归纳，再自上而下表达，才不会为了凑结构而捏造理由。

自下而上 · 发现

事实 → 分组 → 洞察 → 结论

  1. 收集与问题有关的事实
  2. 按同一个维度归组
  3. 为每组写一句含义
  4. 寻找组与组之间的共同结论
适合：问题还模糊、材料很多、结论尚未形成
自上而下 · 交付

答案 → 理由 → 证据 → 行动

  1. 先回答对方真正的问题
  2. 给出同层、同类的关键理由
  3. 把证据放在它所支持的理由下
  4. 说明边界、风险和下一步
适合：汇报、邮件、提案、会议和决策文档

金字塔不是形状，是支持关系

每一层，都要回答上一层的“为什么”

同层内容必须回答同一个问题，并遵循同一种分类维度；上下层之间必须存在可解释的支撑关系。

顶层

一个明确答案

对方读完后应该知道：你建议什么、判断什么，或希望他做什么。

中层

少量平行理由

理由彼此可区分、粒度接近，共同覆盖这次决策真正需要考虑的部分。

底层

可复核的证据

数据、事实、观察、案例和来源要直接支撑其父级理由，而不是只显得“信息很多”。

护栏

反例、边界与风险

说清结论在什么条件下失效、还有什么不知道、还有哪些合理替代方案。

让观点站得住

七个检查点，比套模板更重要

这组检查结合金字塔表达、Toulmin 论证模型和研究写作方法，目标是让观点可以被审查，而不是只显得有说服力。

01

问题

我们究竟在回答哪个问题？对谁、在什么情境下？

02

结论

一句话说出判断或建议，不用“关于……的思考”代替答案。

03

标准

用什么尺度判断优先级、好坏和成功？标准是否得到共识？

04

证据

哪些事实支撑结论？来源、时间、样本与口径能否复核？

05

连接

证据为什么能推出理由？理由为什么能推出结论？补出隐含前提。

06

异议

最强反例和替代解释是什么？什么证据会让你改变结论？

07

行动

谁在什么时候做什么？需要谁确认？下一次检查发生在哪里？

两套常用工具，两个使用边界

SCQA 找问题，MECE 管分组

不要为了展示方法而使用方法。没有真实矛盾时，不必硬造 Complication；没有定义范围时，也不存在绝对“穷尽”。

SCQA

把听众心里的问题叫出来

S · 情境
双方已经同意的少量背景事实
C · 冲突
发生了什么变化、风险或矛盾
Q · 问题
因此现在必须回答什么
A · 答案
你的结论与建议行动
反例：背景占了 80%，真正问题到最后才出现。
MECE

用同一个维度切分同一层

互相可区分
每项有清楚边界，避免一件事重复计算
相对充分
相对于本次目的和范围，关键部分没有明显遗漏
同一粒度
不要把部门、阶段、原因和动作混在一层
可改写
如果现实重叠，就承认重叠并换一个更合适的维度
反例：把“市场、技术问题、提高服务”并列成三个原因。

同一判断，四种交付密度

结构不变，展开程度随场景变化

好的表达不是把所有信息都说完，而是让接收者以最低成本获得当下所需的判断材料。

30 秒

结论 + 影响 + 请求

适合电梯、即时同步和需要快速确认的场景。

3 分钟

再加三条理由 + 主要风险

适合会议发言、口头汇报和初步提案。

一页纸

再加证据 + 备选 + 边界

适合异步决策、跨团队协作和留痕。

完整文档

主体可扫读，细节进附录

适合复杂方案；正文服务判断，附录服务复核。

不做考试式训练

在真实表达中，一次只练一个动作

训练不从背术语开始，而从你明天要发的邮件、要做的汇报和要推动的决定开始。

  1. 01

    一句话压缩

    把一页内容压成“我建议……因为……下一步……”；如果说不出，通常是问题还没想清楚。

  2. 02

    卡片归组

    每张卡只写一个事实，不预设框架；移动卡片直到每组能被一句话概括。

  3. 03

    逆向提纲

    读一篇好文章，只写每段实际完成的作用，再观察它怎样服务中心答案。

  4. 04

    三种对象重写

    分别写给上级、同事和客户，保持事实不变，只调整问题、顺序与展开程度。

  5. 05

    最强反方

    替不同意见构造最有力的理由，再检查自己的证据和边界是否足够。

  6. 06

    行动后复盘

    记录对方真正追问了什么、哪里误解、哪条证据有效，并更新下次可复用结构。

人与 Agent 的结构化协作

Agent 负责铺开与检查，人负责立场与责任

不要只说“帮我润色”。先让 Agent 识别接收者、问题和行动，再做结构工作；否则它只会把混乱写得更流畅。

你

给真实情境

对象、目标、已有材料、限制、不能承诺的事，以及你希望推动的行动。

Agent

给两种分组

说明每种分组所用维度，标出重复、断层、缺证据和隐含前提。

Agent

做反方审查

生成最强异议、替代解释和会改变结论的新证据，而不是只支持你。

你

确认判断

选择问题、标准、结论、边界和最终承诺；涉及他人和外部写入仍由人确认。

Agent

生成多种密度

同时生成 30 秒、3 分钟、一页纸和完整文档版本，保持证据口径一致。

系统

沉淀为 Skill

保存适用条件、输入模板、步骤、检查表、输出格式与失败边界，下次直接复用。

一句可以直接使用的指令

“先不要润色。请识别我在回答的问题、中心结论和接收者；给出两种不同维度的分组，标记每条结论对应的证据、隐含前提、最强反例和适用边界。等我确认后，再生成 30 秒、3 分钟和一页纸三个版本。”

视觉信号帮助学习者找到关键关系

文字与图片之间的提示对理解和迁移呈现小到中等正向效果，对低先验知识者尤其有帮助。

设计含义：标题、分组、连线和空间邻近要服务关系，不作装饰。 21 项研究 · 1,695 人

概念图与批判性思维有关

元分析发现概念图相较传统教学改善批判性思维能力和倾向，但研究异质性中高。

设计含义：把结构画出来，同时保留证据强度与边界。 Higher Education Quarterly · 2025

论证地图研究已形成系统性证据池

综述编码 124 项研究，其中 102 项为实证研究，覆盖协作制图、态度和思维技能。

设计含义：训练应包含“自己建图与修图”，不只观看成品。 Richard Mayer · 学习科学综述

图文有效的前提是减少无关加工

多媒体设计需要控制无关负荷，并通过分段、信号和邻近关系帮助学习者组织信息。

设计含义：图必须解释结构，不能只是漂亮背景。 论证地图 + 自动反馈

即时反馈可以嵌入结构训练

研究展示了学习者构建自然语言论证地图时，系统如何提供自动、实时反馈。

设计含义：Agent 应指出断链与缺证据，而不是替人交答案。 Stephen Toulmin

现实论证需要条件、担保与反驳

主张不只由资料支撑，还依赖连接它们的理由、限定词和可回应的例外。

设计含义：把隐含前提和失效条件显性化。

知名人物的第一性原理

六个镜头，分别纠正六种表达偏差

它们不是同一套理论，却可以共同组成更可靠的表达操作系统。

Barbara Minto

让一个中心点统领材料

表达从读者关心的问题与答案开始；同层观点按一种逻辑分组和排序。

Stephen Toulmin

补出“凭什么能推出”

证据与主张之间总有隐含担保；把它写出来，才能检查论证是否跳步。

Aristotle

逻辑之外还有可信度与关切

只有 logos 不够；接收者还会判断表达者是否可信，以及这件事为何与自己相关。

Herbert Simon

表达是在降低有限理性的决策成本

人无法同时处理无限信息，结构应帮助注意力集中在真正改变选择的变量上。

Richard Mayer

视觉应发出信号，而非制造噪声

标题、空间、颜色和图像要帮助选择与组织信息，删除与目标无关的装饰。

Karl Popper

好观点要允许被推翻

主动说明什么证据会改变结论，比只寻找支持材料更接近可纠错的理性。
